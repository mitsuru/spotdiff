# spotdiff Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rust製の画像diffビューアをKitty Graphics Protocolで描画し、lazygitから全画面で呼び出せるようにする。

**Architecture:** ファイルとGitから取得した画像を、端末に依存しないdiff処理で比較する。表示状態は共通の画像座標で管理し、可視領域だけをワーカーでリサイズ・エンコードする。TUIは入力、描画、端末の復元を担当する。

**Tech Stack:** Rust 2024、Git CLI、clap、image、ratatui、crossterm、ratatui-image、std::thread/mpsc。

**Spec:** [承認済み仕様](../specs/2026-09-28-spotdiff-design.md)。2026-09-28にユーザーがLGTMを返した版を実装する。

## Global Constraints

- 静止画像のPNG、JPEG、WebPを読み込む。
- 比較キャンバスは両画像の幅・高さそれぞれの最大値とし、両画像を左上に揃える。サイズ変更を自動で正規化しない。
- 倍率は1/16倍から16倍までとし、フィット倍率は別途計算する。
- 初期版では各入力のデコード後のRGBAサイズと比較キャンバスサイズをそれぞれ256 MiB以下に制限し、オーバーフローする寸法は拒否する。
- 正常なビューア終了の終了コードは差分の有無によらず0とする。
- 描画に使用した画像だけを削除し、端末内の他の画像を一括削除しない。
- Kitty方式を選択し、非対応環境で文字による画像表示へ自動で切り替えない。
- 設定例はリポジトリに置き、ユーザーのlazygit設定ファイルへの書き込みは行わない。
- 自動テストだけでKitty描画やlazygitへの復帰が検証済みとは扱わない。
- 初期版はコミット間比較、リネーム追跡、LFSの展開、SVG、アニメーション、マウス操作、tmuxの動作保証を追加しない。

## Review Focus

1. 改行、引用符、先頭のハイフンを含むGitパスも、別引数や別ファイルとして解釈しない（Task 1）。
2. 削除済みパスやリポジトリ外へ向いたシンボリックリンクでも、パス解決とエラー分類が一貫する（Task 1）。
3. merge conflictでindexのstage 0がない画像を、新規追加と誤認しない（Task 1）。
4. ファイル名の制御文字で見出しや端末を壊さず、長い日本語名でも画面内に収める（Task 4）。
5. 連続ズーム中にワーカーが遅れて完了・失敗しても、古い結果で最新表示を上書きせず、終了できる（Task 4、5）。

## 実行環境と依存

作業ディレクトリは新規で、現状の`.git`は空かつ読み取り専用のためGitリポジトリとして利用できない。実装ファイルはこのワークスペースに保存し、Gitテストには`tempfile`で作る一時リポジトリを使う。Git管理が利用できる場合にだけ各Task後に対象ファイルをコミットし、`.git`の置き換えは行わない。

利用可能なRustは1.96.0、lazygitは0.65.0。Kitty実機はまだ確認できていない。依存取得が必要な場合は書き込み可能な`/tmp/spotdiff-cargo`をCargo homeに使い、既存キャッシュから必要なcrateを再利用する。ネットワーク制約で取得できない依存は明記し、別バージョンへ無断で置き換えて検証済みとは扱わない。
