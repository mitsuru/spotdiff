# 実装・検証記録

2026-09-28に初期版を実装した。2ファイル、index→作業ツリー、HEAD→indexの比較をKitty Graphics Protocolで表示する。lazygitのカスタムコマンドから全画面で開く設定例を提供する。

Rustテスト39件、端末PTYテスト5件、実lazygit 0.65.0を使用するPTYの4シナリオが通過した。fmt、Clippy、releaseビルドも通過。Kitty問い合わせは模擬応答のため、実際の画像の見え方は未確認。[実機検証手順と実施範囲](manual-testing.md)を参照。

独立レビューで報告された重要な4件は、再現テストの失敗を確認して修正した。

- エラー出力のファイル名に含まれる端末制御文字を無害化。
- 297セルを超える領域での画像欠落を防ぎ、フィットと移動範囲を同じ領域に揃えた。
- `git add -N`の空blobを通常の空ファイルと区別し、比較元を画像なしとして扱う。
- FIFO・デバイスなど通常ファイル以外を読み込み前に拒否。

レビューのテスト面の2件も最終検証に含めた。PTYでは15回の画像送信の完了を待って個別に操作し、2回の端末サイズ変更を行う。世代の古い成功・失敗結果は実際の採用処理に注入して破棄を確認する。保留した軽微な指摘はない。

## 実装中の判断

判断を行った順に記載する。

| 判断と理由 | 制約・負担 |
| --- | --- |
| `.git`が空かつ読み取り専用のため、認可された作業ディレクトリで直接実装。 | worktree・コミット履歴による復旧がない。 |
| `/tmp`の容量不足を受け、Cargoキャッシュを`.superpowers/cargo`へ変更。 | ローカルのディスク容量を使用する。 |
| ワーカーへの要求送信をResultにして、切断を明示的に伝える。 | 呼び出し側にもエラー伝播処理が必要。 |
| 日本語の表示テストではTestBackendの文字継続セルの空白を正規化。 | ラベル内の意図的な空白そのものは検証しない。 |
| Pickerの入力ごとにリセットされるタイムアウトを補うため、問い合わせ全体を3秒に制限。 | 非常に遅い端末応答は失敗する。 |
| Pickerによるtmux設定変更を避け、問い合わせ前にtmux/screenを拒否。 | 初期版ではマルチプレクサーを扱わない。 |
| ライブラリのFontSize構造体をアプリの寸法タプルへ変換。 | 追加の制約はない。 |
| panic検証用バイナリをtests/supportのCargo exampleとして配置。 | 開発用バイナリが1つ増える。 |
| CLIエラーテストはraw mode開始前の検証としてTask 5で実装。 | Task 6の一部を前倒ししただけで機能上の制約はない。 |
| 描画ライブラリの上限に合わせ各画像領域を297列×297行に制限。 | 大きな端末には使わない余白ができる。 |
| 空のindex blobに限りGit diffのITAの可視・不可視なraw出力を比較。 | Git呼び出しが2回増え、実験的なITAオプションに依存する。 |
| リサイズと遅延結果のテストの不足を、計画で約束した最終検証の中で補った。 | テストの変更と結果採用処理の関数抽出が増えた。 |
| アニメーション・全フレーム比較は静止画像の初期仕様どおり対象外。 | アニメーション全体は比較できない。 |
| SVG・LFS展開・リネーム追跡は初期仕様どおり対象外。 | 別ツールまたは将来の拡張が必要。 |
| 最終レビューでもtmux/screenは対象外という判断を維持。 | 対応端末で直接実行する必要がある。 |
| ICC色管理・EXIF自動回転は追加せず、デコードした値を比較。 | 色管理を行う画像ビューアと見え方が異なる場合がある。 |
| Windowsでのパス・PTY動作は未検証として記載。 | Windowsでの動作は保証しない。 |
| 実lazygit 0.65.0で終了後のEnterが必要なことを確認し、設定例・READMEに記載。 | 復帰までに1キー追加される。 |
| Kitty実画面を確認できないため、模擬応答の検証と実画面の確認を区別。 | 画像の見え方・残留は実機確認が必要。 |
| コミット履歴が使えないため、実行台帳を削除せず、この文書にも判断を保存。 | Gitから無視されるローカルログが残る。 |

GitのITAオプションは[公式Git diff仕様](https://git-scm.com/docs/git-diff)を参照。lazygit連携は[公式カスタムコマンド仕様](https://github.com/jesseduffield/lazygit/blob/v0.65.0/docs/Custom_Command_Keybindings.md)の`output: terminal`を使用する。

初期実装時点では、ユーザーのlazygit設定への書き込み、コミット、merge、公開は行っていない。実装完了後にGit管理が利用可能になり、ユーザーの指示で初期実装をコミットする。
